# Waxwing logo — concept 4

A vector recreation of the supplied “Minimal flight lines” concept.

## Files

- `waxwing-logo.svg`: bird and outlined wordmark; transparent background.
- `waxwing-mark.svg`: bird only; transparent background.
- `waxwing-logo.png`: 2048 px wide transparent PNG export.
- `waxwing-preview.png`: 530 px wide preview on white.

All artwork consists of editable vector paths. There are no embedded raster images, external resources, scripts, filters, or font dependencies. Individual feathers, the crest, the head/breast, and wordmark letters have descriptive IDs. The wordmark uses outlined Times New Roman capitals, individually fitted to the reference spacing; it is an approximation of the generated lettering.

## Editing and export

Open either SVG in a vector editor such as Inkscape, Illustrator, or Figma. Ungroup to edit individual shapes. The SVG viewBox preserves the proportions at any export size. Set PNG export width as needed and retain alpha transparency, or add a background color in your editor.

Palette:
- Navy: `#10212D`
- Coral: `#BD6048`

The master uses flat colors and smooth Bézier outlines to reproduce the supplied raster concept with clean edges at larger sizes. The smallest feather details naturally become less visible at very small icon sizes.
